### Hasil kajian Mac 2018

Rencana ini adalah berdasarkan isu tercipta yang bertajuk
"Kajian projek tercipta" (16 Mac 2018)[^1]. Semua komen pada
isu tersebut telah disalin, disemak, dan disusun semula
mengikut tarikh dan tajuk kecil.

Kajian telah dibuat lebih awal daripada isu tercipta,
tetapi tidak ditulis dalam bentuk rencana sehingga beberapa
bulan kemudian. Rencana ini boleh didapati di laman sumber
bermula 20 November 2018 (7b6fd49).

#### 9 Mac: Tinjauan

Tinjauan awal mendapati ada dua sumber dan sembilan projek
yang boleh dicapai seperti berikut.

Senarai sumber perkamusan:

- Wiktionary:Public domain sources[^2]
- goldendict/goldendict Wiki[^3] -- GitHub

Senarai projek tercipta:

1. DanielAmani/KamusBahasaMelayu[^4] -- GitHub
2. dolph/dictionary[^5] -- GitHub
3. adambom/dictionary[^6] -- GitHub
4. dwyl/english-words[^7] -- GitHub
5. FOLDOC - Computing Dictionary[^8]
6. Cari Makna Perkataan Bahasa Malaysia[^9]
melalui /r/malaysia[^10]
7. lukluk/database_bahasa[^11] -- GitHub
8. andrisetiawan/lexicon[^12] -- GitHub
9. matbahasa/MALINDO_Morph[^13] -- GitHub

Senarai projek telah dikumpul melalui carian semula di
GitHub menggunakan beberapa kata kunci berikut:
"bahasa melayu", "kosa kata" dan "data bahasa".

#### 19 Mac: Kesimpulan

Berdasarkan carian yang dilakukan sejak 10 hari lepas
(9 Mac 2018) hingga hari ini (19 Mac 2018):

- `DanielAmani/KamusBahasaMelayu` adalah satu-satunya projek
sumber terbuka yang mengusahakan kamus bahasa Melayu di
GitHub; bagaimanapun, projek ini kelihatan tergendala,
format data adalah bukan mudah alih (HTML) dan kata masukan
tidak lengkap (abjad A-E sahaja).

- `makna.online` tidak mempunyai sumber terbuka yang boleh
diselidik.

- `lukluk/database_bahasa` dan `andrisetiawan/lexicon` ialah
senarai kata masukan dalam bahasa Indonesia tanpa makna.

- `matbahasa/MALINDO_Morph` ialah kamus morfologi untuk
bahasa Melayu/Indonesia, iaitu jenis kamus yang bukan untuk
kegunaan umum.

Carian luar membawakan laman Wikikamus, iaitu projek kamus
sumber terbuka oleh Yayasan Wikimedia, bermula
12 Disember 2002. Juga digelar Wikikamus atau KamusWiki.

Wikikamus ada senarai sumber untuk penterjemah[^14].
Malangnya, kebanyakan pautan luar telah mati dan hanya
tinggal dua sumber yang masih hidup (sehingga 19 Mac 2018):

- E-istilah - Carian Istilah Anda[^15]
oleh Universiti Teknologi Malaysia Skudai, dengan kerjasama
Dewan Bahasa Dan Pustaka; merangkumi 5000 istilah komputer &
8600 istilah kejuruteraan

- Istilah IT[^16]
oleh Sabah Edu .net; merangkumi lebih 500 istilah IT

Dari segi lesen, kebanyakan projek-projek tercipta tidak
mengikut pelesenan yang disarankan atau tidak dihiraukan
langsung. Projek-projek ini dilihat tidak ada kecenderungan
(trend) ke arah sumber terbuka untuk memudahkan penggunaan
semula data.

Dari segi kata masukan, bahasa Melayu tidak mempunyai jumlah
kata masukan yang lazim. Projek-projek tercipta hanya
mengandungi kata masukan sebanyak mungkin, tetapi tidak
lengkap atau tidak mengambil tahu tentang kata masukan yang
kerap digunakan.

Kesimpulannya, tidak ada projek tercipta yang masih
mengusahakan kamus bahasa Melayu sebagai sumber terbuka
(sehingga 19 Mac 2018).

#### Pasca-19 Mac

Enam bulan kemudian, semakan bersahaja mendapati salah satu
projek tercipta `DanielAmani/KamusBahasaMelayu` menyerupai
format kata masukan Kamus Dewan. Barangkali Edisi Keempat
sebab ada tambahan kata masukan asing. Walaupun dilesenkan
di bawah domain awam, sumber ini *tidak wajar* digunakan.
